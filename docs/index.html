Three Layers: Cluster Provisioner, Platform, Tenant

Everything in a shared cluster lab is organized into three distinct layers. Understanding this separation is the most important concept before reading anything else.

🔷 Cluster Provisioner 🟣 Platform 🟠 Tenant
Run once per cluster Managed by ArgoCD continuously Run on every order
RHDP ops / AGV catalog item Bootstrapped by cluster provisioner This is your catalog item
Installs operators, RHBK, ArgoCD, ToolHive Cluster monitoring, future platform resources User, namespaces, Gitea, workloads
Registers cluster in Sandbox API pool Shared across all users on the cluster Scoped to one user / one order
NOT in your catalog item NOT in your catalog item This is your common.yaml + workloads + GitOps
